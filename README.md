# Super AI Engineer Season 6 (2026)

Super AI Engineer Season 6 Online Hackathon Competition. This hackathon is part of Level 1 of the
program. This repo covers my Level 1 hackathon work for the season, split into **6 independent
competitions**, each in its own top-level folder below.

## About the program

[Super AI Engineer](https://superai.aiat.or.th/en/home/) is an intensive, no-prior-experience-required
AI upskilling/reskilling program run by the **Artificial Intelligence Association of Thailand (AIAT)**,
supported by MHESI, TSRI, NECTEC, and partner universities. It runs as a blended pathway — application,
self-paced online coursework, then intensive bootcamp/hackathon rounds — and standout participants can
go on to internships with partner organizations. Season 6 is the program's sixth annual iteration
(seasons run 2020–present). This repo holds my work for Season 6's hackathon track.
